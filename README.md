Snake Game

This is a classic Snake game implemented in Java. The player controls the snake using the arrow keys (Up, Down, Left, Right) to navigate and collect food items. Pressing the Shift key temporarily speeds up the snake for added challenge.
Features:

  1. Three types of food with different point values:
      1.1. Regular food (1 point)
      1.2. Special food (3 points)
      1.3. Bonus food (5 points)

  2. Real-time score tracking displayed on the game screen.

  3. High scores are maintained and displayed during gameplay.

  4. Each player's scores are saved in a text file, allowing persistent tracking of all players’ game performances.

Enjoy the nostalgic fun with a modern twist on scoring and speed control!
